# Mini Data Platform (BigQuery)

## Описание

Тестовый учебный проект по построению аналитической платформы на данных такси

## Стек

* BigQuery
* SQL
* GitHub

## Архитектура

RAW → STAGING → MARTS → DATA MART

## Реализовано

- загрузка и очистка данных
- построение staging слоя
- star schema (fact_trips + dimensions)
- витрины (daily metrics, company metrics)
- data quality проверки

## Что удалось узнать

* data modeling (fact/dimension)
* работа с BigQuery
* построение витрин
* базовые data quality тесты
